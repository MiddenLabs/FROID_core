[FRD_TOOL] is the node that describes a namespace root's tooling, and its body sets the affirmative rules and the restrictions that every tool of the record must satisfy. The rules require each tool to serve a single purpose and to validate and construct exactly one invariant, to be idempotent, and to recompute the invariant it checks rather than trust a stored result; a tool chooses between its two directions with a flag, writes any file atomically by writing to a temporary name and renaming it, and returns a failed validation as a non-zero exit status under the process return convention named by [UNIXRTRN]. [FRD_TOOL] also serves as the catalog under which the individual tool nodes are gathered. Its restrictions forbid a tool's validation direction from altering the namespace at all, and forbid any tool from executing the content of a [FOLIO], so the record is read as data and never run. Every checker overlay in the catalog carries a reciprocal back to that cataloging rule, and the realization nodes for particular languages cite this node as the contract they realize.
