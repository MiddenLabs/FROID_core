[FILEHAND] is a catalog node that gathers the file handling standards the system relies on. Its single rule states only that the node catalogs those standards, so it carries no constraints of its own on how files are written or read; the substance lives in the nodes it collects, which name the specific formats. Those collected nodes are [MARKDOWN], [YAML], and [CSV], each of which cites this catalog as the reason it belongs here. [FILEHAND] is itself one of the catalogs held by the namespace root, [SYSROOT], which places file handling standards among the top-level divisions of the record.
