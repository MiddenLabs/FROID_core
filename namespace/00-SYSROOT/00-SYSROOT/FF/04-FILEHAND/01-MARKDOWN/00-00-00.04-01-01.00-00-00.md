[MARKDOWN] is the node that fixes the text format the system uses, and it does so by pointing outward rather than by describing the format itself. Its one rule binds [MARKDOWN] to a named external specification, CommonMark 0.31.2, with a note giving that specification's address; no syntax is restated in the body. The node sits in the [FILEHAND] catalog of file handling standards, which is where its membership is accounted for. Because the record's own documents are written in this format, a wide set of nodes lean on it — among them the section nodes that name the parts of a body, the body node [FRD_BODY], and the file type node [TYP_MKDN] — so a change to the format this node names would reach all of them.
