[YAML] is the node that fixes the data serialization language the system uses. Its single rule binds the node to the external specification YAML 1.2.2, and a note records where that specification is published; the body defines no syntax of its own. The node belongs to the [FILEHAND] catalog of file handling standards. The file type node [TYP_YAML] is the one place in the record that leans on this binding, applying it where serialized data is stored.
