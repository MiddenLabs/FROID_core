[CSV] is the node that fixes the tabular text format the system uses. Its one rule binds the node to the external specification RFC 4180, with a note giving that document's address, so the body states no field, quoting, or line-ending conventions itself. The node is held by the [FILEHAND] catalog of file handling standards. The file type node [TYP_CSV] leans on this binding at several points, which is where the tabular files of the record take their shape.
