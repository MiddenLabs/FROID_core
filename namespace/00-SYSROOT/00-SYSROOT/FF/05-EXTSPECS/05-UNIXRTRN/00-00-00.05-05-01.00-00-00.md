[UNIXRTRN] is the process return convention used by the system, and its body is a small set of rules fixing both the source of the convention and how its values are read. One rule pins the definition to POSIX.1-2017, whose address is recorded in the node's notes; the others state that a status of zero signals success, that any status other than zero signals failure, and that a status is an integer from 0 through 255. It is a member of [EXTSPECS], the catalog of external specifications, and answers that node's cataloguing rule. [FRD_TOOL] refers back to it in requiring that a tool exit per this convention, so a tool's exit grade is read exactly as the rules here describe.
