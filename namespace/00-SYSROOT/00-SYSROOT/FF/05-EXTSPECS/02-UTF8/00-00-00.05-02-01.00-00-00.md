# 00-00-00.05-02-00.00-00-00

[UTF8] is the text encoding used by the system. Its body carries a single rule, that UTF8 is defined by RFC 3629, with the specification's address recorded in the node's notes. It is a member of [EXTSPECS], the catalog of external specifications, and answers that node's cataloguing rule. The file-type nodes that declare an encoding — [TYP_MKDN], [TYP_BASH], [TYP_PYTH], [TYP_YAML], [TYP_CSV] and [TYP_TXT] — all point back to it, so every text artifact in the record is encoded as this node fixes.
