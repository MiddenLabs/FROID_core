[RUST] is the node that names one of the programming languages the system uses. One rule binds the node to a named external version, Rust 1.85, with a note giving the address of its documentation; a second makes the node a catalog of the configurations under which the language may be used. The node belongs to the [LANGDEFS] catalog of language definitions, and that catalog's first-position ordering rule is what makes one configuration the default. The single configuration held here is the realization overlay [RUSTREAL], which occupies that position. Unlike the other languages of the catalog, no file type node cites this one.
