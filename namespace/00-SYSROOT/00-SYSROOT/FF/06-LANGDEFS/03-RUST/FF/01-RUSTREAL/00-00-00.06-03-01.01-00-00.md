# 00-00-00.06-03-00.01-00-00

[RUSTREAL] is an overlay node: it describes no object, exposing only a seam that states the terms on which a tool is bound to a language. Two terms are stated. The first says that a tool of [FRD_TOOL], the namespace root's tooling, realized under this overlay is realized in [RUST]; the second says that this overlay is the default configuration of [RUST]. The second term answers the configuration catalog rule in [RUST] and takes effect through the first-position ordering rule held by [LANGDEFS]. The seam says nothing about how such a tool is built — it names the language of the realization and stops there.
