# 00-00-00.06-02-00.01-00-00

[BASHREAL] is an overlay node: it carries no description of an object, only a seam stating the terms on which a tool is bound to a language. It holds two terms. The first says that a tool of [FRD_TOOL], the namespace root's tooling, realized under this overlay is realized in [BASH]; the second says that this overlay is the default configuration of [BASH]. That second term answers the configuration catalog rule in [BASH] and takes effect through the first-position ordering rule held by [LANGDEFS]. The seam exposes nothing further — it selects the language of a realization and leaves the writing of the tool to the tooling rules themselves.
