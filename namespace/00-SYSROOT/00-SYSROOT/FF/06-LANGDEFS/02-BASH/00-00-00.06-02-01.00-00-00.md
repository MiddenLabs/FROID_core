[BASH] is the node that names the shell scripting language the system uses. One rule binds the node to a named external version, Bash 5.2, with a note pointing to the manual; a second makes the node a catalog of the configurations under which the language may be used. The node belongs to the [LANGDEFS] catalog of language definitions, whose first-position ordering rule settles which of those configurations is the default. The configuration held here is the realization overlay [BASHREAL], which takes that default position, and the file type node [TYP_BASH] leans on the version binding stated here.
