[PYTHON] is the node that names one of the programming languages the system uses. One rule binds the node to a named external version of the language, Python 3.14, with a note giving the address of its documentation; a second rule makes the node a catalog in its own right, holding the configurations under which that language may be used. The node belongs to the [LANGDEFS] catalog of language definitions, and the first-position ordering rule of that catalog is what makes one of its configurations the default. The configuration it holds is the realization overlay [PYTHREAL], which claims that default position. The file type node [TYP_PYTH] also leans on the version binding stated here.
