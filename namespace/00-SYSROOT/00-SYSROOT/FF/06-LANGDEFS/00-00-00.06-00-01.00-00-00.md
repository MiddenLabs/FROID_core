[LANGDEFS] is a catalog node that gathers the programming and scripting languages the system defines. One rule states that the node catalogs language definitions; a second is substantive and general, holding that where a language offers several configurations, the one in first position is its default. That ordering rule is what lets each language below it name a default without restating the choice, and the languages collected here — among them [PYTHON], [BASH], and [RUST] — cite this catalog as the reason they belong. [LANGDEFS] is itself one of the catalogs held by the namespace root, [SYSROOT].
