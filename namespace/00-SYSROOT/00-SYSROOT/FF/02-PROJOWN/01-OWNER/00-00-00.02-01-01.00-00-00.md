[OWNER] is the catalog of this namespace root's owners, the single node held by [PROJOWN] and the place where each owner described by [OWN_OWNR] gets an actual entry. Its one rule says that it catalogs owner records, so its body governs only membership: an owner exists in this record by having a node beneath [OWNER], and nowhere else. The abstract description of what an owner record means, including that it identifies a depositor and that it neither authenticates nor authorizes anyone, belongs to [OWN_OWNR] rather than here. The entries themselves are thin nodes whose substance is the set of folios that name them as owner.
