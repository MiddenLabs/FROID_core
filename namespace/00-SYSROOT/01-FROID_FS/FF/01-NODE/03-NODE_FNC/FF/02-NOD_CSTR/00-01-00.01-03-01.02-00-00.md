# 00-01-00.01-03-00.02-00-00

[NOD_CSTR] is the segment function that increases constraint through the parent and child relationship, so that moving down the tree narrows what a node covers. Its rules require constraint to increase from a parent node to its child, require sibling nodes to take distinct values at that position, and state that a leaf node has no child constraint below it. The node is cited by the file system rules that lay out the tree, by the identifier conversion procedure, by [NOD_BLOK] where every segment before a block's closing bins is a constraint segment, and by the time projection. Its body is short because the whole of its content is the ordering guarantee that makes an identifier readable as a path of narrowing meaning.
