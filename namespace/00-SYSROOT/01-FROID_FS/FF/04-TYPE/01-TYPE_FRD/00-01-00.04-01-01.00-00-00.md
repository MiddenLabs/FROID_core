# 00-01-00.04-01-00.00-00-00

[TYPE_FRD] is the node that catalogs the artifact kinds the system defines, the roles a file can play inside a [FOLIO] rather than the file formats those roles are written in. Its body carries one rule, which states exactly that: [TYPE_FRD] catalogs defined artifact kinds. Everything below it names one such kind, among them the abstract of a folio, its manifest, its normative body, and its decision, defect, index, and miscellaneous artifacts. It answers back to [TYPE], which catalogs type families, and to the node that governs how a filename's numbering selects one of these kinds, so that the kind of an artifact can be read off its name.
