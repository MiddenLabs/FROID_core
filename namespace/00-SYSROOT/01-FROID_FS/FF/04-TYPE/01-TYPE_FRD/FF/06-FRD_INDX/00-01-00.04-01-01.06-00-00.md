# 00-01-00.04-01-00.06-00-00

[FRD_INDX] is the record type for a one-to-one mapping of node tags to node identifiers, written as a CSV file named for the node tag it indexes. Its rules fix the file's shape: the tag in the first column, the node identifier in the second, and the terminal digest of each folio in the third, with the tag rows ordered by node identifier. They also fix its versioning, a second row carrying a version number that is the SHA-256 digest of the full tag rows of [FOL_INDX], each line feed terminated, written as null when the file is created and filled in at deposition. Its restrictions forbid two entries sharing a node tag and reserve the two manifest-style field names from being used as tags. Its failure modes name a duplicate tag and a version number that does not match the digest of the tag rows it covers, and its reciprocals record that [FOL_INDX] and [TYPE_FRD] cite it along with the index-building checks.
