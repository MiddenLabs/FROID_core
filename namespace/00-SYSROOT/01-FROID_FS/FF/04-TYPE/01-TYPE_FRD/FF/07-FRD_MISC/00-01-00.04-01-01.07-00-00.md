# 00-01-00.04-01-00.07-00-00

[FRD_MISC] is the catch-all artifact kind in the catalog of artifact kinds held by [TYPE_FRD]: it covers any file belonging to a [FOLIO] that is not one of the specifically defined artifact kinds, and it may be of any file type listed in [TYPE_TYP]. Its rules say that a [FRD_MISC] takes its definition from its [TYPE_TYP] rather than from a shape of its own, that each one is attached either to [MODE_ONE] or to [MODE_TRE], and that within a single [FOLIO] the several [FRD_MISC] files are distinguished from one another by file extension. A further rule places a [FRD_MISC] of [MODE_TRE] in the directory of its own [FOLIO], which qualifies the general rule of [MODE_TRE] that realized artifacts sit outside the namespace. The accompanying note explains the split: a [FRD_MISC] counts as [MODE_ONE] when it is itself canonical matter expressed in some other format, and as [MODE_TRE] when it is instead derived from the [FRD_BODY], so an illustrative code block or configuration example is treated as a realization unless it has been declared canonical.
