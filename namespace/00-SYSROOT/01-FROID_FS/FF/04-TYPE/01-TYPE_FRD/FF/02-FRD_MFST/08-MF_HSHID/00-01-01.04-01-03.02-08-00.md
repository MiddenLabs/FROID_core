## Definition

- [MODE_ONE]
- [MF_HSHID] is a [TYP_YAML] field containing the [SHA256] of the identity fields

## Rules

- A01: [MF_HSHID] is [SHA256]
- A02: [MF_HSHID] hashes, each value line feed terminated, the text values of the following fields in order:
  1. mf_nodid
  2. mf_nodtg
  3. mf_locus
  4. mf_atch
  5. mf_owner
  6. mf_depst
  7. mf_sprup

## Restrictions

- B01: [MF_HSHID] does not hash all fields in [FRD_MFST]

## Reciprocals

- FRD_MFST:A01
- FRD_MFST:A06
- MF_HSHSP:A02
