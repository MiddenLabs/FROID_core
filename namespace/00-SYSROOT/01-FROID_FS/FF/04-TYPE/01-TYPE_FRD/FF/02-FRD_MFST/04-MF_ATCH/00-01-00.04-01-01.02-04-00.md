# 00-01-00.04-01-00.02-04-00

[MF_ATCH] is the manifest field that records how the folio attaches to the namespace, carrying the [FLIO_TCH] value that distinguishes an artifact holding a structural place in the tree from one overlaid onto it. Its single rule requires the value to be a valid [FLIO_TCH], so attachment is declared from the fixed set that node defines rather than inferred from location. It is the fourth field of a [FRD_MFST] in the fixed order, and it answers back to that ordering rule and to the field-validation seam that checks attachment values. Its value is among those folded into the manifest's identity hash.
