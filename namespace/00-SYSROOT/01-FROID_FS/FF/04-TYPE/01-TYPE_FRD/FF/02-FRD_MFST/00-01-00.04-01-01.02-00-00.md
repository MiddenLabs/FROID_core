# 00-01-00.04-01-00.02-00-00

[FRD_MFST] is the artifact kind that describes a [FOLIO]: a YAML document, defined by [TYP_YAML] and named for the folio's tag, whose fields record the folio's identity, provenance, and content hashes. Its rules fix the field order strictly, requiring [MF_NODID], [MF_NODTG], [MF_LOCUS], [MF_ATCH], [MF_OWNER], [MF_DEPST], [MF_SPRUP], and [MF_HSHID] in that sequence, and permitting [MF_ARFCT], [MF_HSHAR], [MF_SPRDN], and [MF_HSHSP] to follow, also in order. The hash fields are governed by their own timing: a manifest is created with them empty, writes them at deposition, and writes the supersession-downward fields only when the folio is later superseded, with [MF_HSHID], then [MF_HSHAR], then [MF_HSHSP] each being the terminal hash as the chain grows. A single restriction forbids whitespace inside any field value. Each named field has its own node below [FRD_MFST], which defines what that field must contain.
