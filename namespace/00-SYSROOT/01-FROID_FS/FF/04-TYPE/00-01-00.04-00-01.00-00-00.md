# 00-01-00.04-00-00.00-00-00

[TYPE] is the node that holds the system's catalog of type families, the families that describe the kinds of files the system uses. Its body is a short set of rules: it declares that cataloging type families is what [TYPE] does, and it requires every member of that catalog, each [TYPE_TYP], to carry a reference to its own [NODE_ID] in the first available position of the file, so a file can name itself. A single restriction conditions that requirement for the binary family, [TYP_BLOB], which is an opaque sequence of bytes and therefore has no first available position in which a [NODE_ID] could be written. [TYPE] sits beneath the filesystem node of the record and answers back to it, and its two children divide the catalog between the artifact kinds the system itself defines and the content types those artifacts are written in.
