# 00-01-00.04-02-00.03-00-00

[TYP_CSV] is the entry in the [TYPE_TYP] catalog for tabular data, described as the system's own profile of the external standard [CSV], and it is the type in which the index artifact [FRD_INDX] is written. Its rules adopt that standard and then narrow it: the column delimiter is the comma, the quote character is the double quote, a quote inside a quoted field is escaped by doubling it, whitespace counts as part of a field's value, every record including the last ends in a line break, and the encoding is [UTF8]. Two of the rules deliberately override the external standard, choosing a line feed as the record terminator rather than the carriage-return pair, and forbidding a line break inside a field; a third rule defers the remaining quoting questions to a determination made at the namespace root. The restrictions rule out backslash escapes, blank lines, comment lines, and a leading byte order mark, and the one recorded failure mode is a file that turns out not to be valid [UTF8]. A final rule records that this entry covers both the ordinary tabular extension and the extension used for the system's tag maps.
