# 00-01-00.04-02-00.05-00-00

[TYP_BASH] is the entry in the [TYPE_TYP] catalog for shell script files. Its rules refer the format to the external standard [BASH], require the file to begin with a shell shebang, and then require the identifier of its node to be declared as a comment on the second line, immediately after that shebang. The encoding is fixed as [UTF8], and a final rule records that the entry covers the shell script filename extension. The ordering of the first two rules is what distinguishes this entry from [TYP_PYTH], where the shebang is forbidden and the identifier takes the first line instead.
