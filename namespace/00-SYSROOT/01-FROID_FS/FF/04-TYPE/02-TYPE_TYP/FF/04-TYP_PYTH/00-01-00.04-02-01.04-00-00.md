[TYP_PYTH] is the entry in the [TYPE_TYP] catalog for python source files. Its rules refer the format to the external standard [PYTHON], fix the encoding as [UTF8], require the file to declare the identifier of its node as a comment on the first line, and record that the entry covers the python filename extension. Its restrictions keep that first line clear: such a file does not begin with a shebang and does not carry a language encoding declaration. The restrictions and the identifier rule work together, since the rule that every file type entry place its node identifier in the first available position leaves no room for competing first lines.
