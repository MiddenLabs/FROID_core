# 00-01-00.04-02-00.01-00-00

[TYP_MKDN] is the entry in the [TYPE_TYP] catalog for the system's document format, the type used by the written artifact kinds such as [FRD_BODY], [FRD_SMRY], [FRD_ADR], and [FRD_BUG]. Its rules point outward to the external standard [MARKDOWN] for the format itself and to [MKDNLINT] for the style the system holds its documents to, and they fix the encoding as [UTF8]. A further rule requires every such document to declare the identifier of its node as the first entry in the file, written as a level-one heading, and the node gives worked examples of that heading. The last rule states which filename extension this entry covers, namely the markdown extension.
