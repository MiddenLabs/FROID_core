# 00-01-00.04-02-00.00-00-00

[TYPE_TYP] is the catalog of file types the system uses, standing beside [TYPE_FRD] as one of the two type families gathered under [TYPE]. Its rules require that the catalog list the file types actually in use, that every artifact of a used file type be created with all of its fields populated, that a single entry in the catalog may cover one or more filename extensions, and that an artifact declare which entry it belongs to through its own filename extension. The children of this node are the individual entries, among them [TYP_MKDN], [TYP_YAML], [TYP_CSV], [TYP_PYTH], [TYP_BASH], [TYP_TXT], and the catch-all [TYP_BLOB]. It is the node that [FRD_MISC] depends on when it says an artifact of no defined kind is nonetheless defined by its file type, and the node whose entries [TYPE] requires to carry a reference to their own identifier in the first available position of a file.
