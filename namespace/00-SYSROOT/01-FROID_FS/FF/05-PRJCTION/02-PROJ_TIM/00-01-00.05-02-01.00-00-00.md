# 00-01-00.05-02-00.00-00-00

[PROJ_TIM] is the part of a namespace root's projection catalog that holds the root's time. Its rules are short: it catalogs that time, and it governs how an encoded time is laid out when the namespace is stored as a filesystem tree. A directory that renders the [TIM_TIME] encoding takes the encoded value itself as its name, which conditions the general filesystem rule that a constrained directory carrying a folio is named from its segment and tag; and a trailing zero [ND_SGMNT] of an encoded time does take a directory, conditioning the filesystem rule that otherwise gives trailing zero segments no directory at all. Both rules are therefore exceptions granted to time and to nothing else. The time itself is described by [TIM_TIME] beneath this node; [PROJ_TIM] states only that a namespace root has such a time and how it comes to rest in the tree.
