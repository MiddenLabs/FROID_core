[MODE] names the aspect of a [NODE] that a given [FRD_BODY] describes, and its own body is a catalog rather than a substantive specification. Its two rules state only that it catalogs the modes, and that a mode may be carried in any of the file types listed in the type catalog. The substance sits in its three children: [MODE_ONE] for the object itself, [MODE_TWO] for the surface it exposes, and [MODE_TRE] for its realization. Because every body and every artifact filename must be classified by mode before it can be placed, a number of other nodes cite this one, including the file system node, the body node, and the bin node that carries the classification code.
