# 00-01-00.02-02-00.01-00-00

[FOL_STRC] is one of the two attachments that [FLIO_TCH] allows for a [FLIO_ART]: the attachment of an artifact that is part of the namespace structure. Its rules state that such an artifact fixes the position of its [NODE] in the namespace, and that a node so attached requires a [FOLIO] — structure and record go together, with no structural position left undocumented. Its restriction holds that a structural leaf node does not carry a [MODE_TWO], so a node at the bottom of the structure describes only itself and exposes no seam. This is the counterpart of [FOL_OVLY], which applies to a node wherever it sits and defines no position at all.
