[FLIO_ART] is the catalog of artifact roles — the node that enumerates what any single file in a [FOLIO] can be. Its rules close that set to four roles: [FOL_BUG], [FOL_INDX], [FOL_MFST], and [FOL_TYPE], each defined by its own node. A second rule requires every artifact to declare its [NODE_ID] in its first available position, which is how a loose file is tied back to the node it belongs to. The restriction admits the one case where that is impossible — a [TYP_BLOB] artifact, being opaque bytes, has no first available position for an identifier — and so conditions the declaration rule rather than breaking it. Because this node names the roles, most of the rest of the record about loci, attachments and manifests is written in terms of it.
